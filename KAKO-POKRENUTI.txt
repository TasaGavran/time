Kako da sajt pravilno otvorite (Live Server, Cloudflare, linkovi)
==================================================================

Produkcija (Cloudflare Worker + ASSETS):
----------------------------------------
- Samo git push na GitHub NE ažurira Worker automatski, osim ako niste povezali CI.
- Posle izmena uvek pokrenite iz korena repoa (gde su wrangler.toml i worker.js):
    npx wrangler deploy
- Stranice koriste apsolutne putanje (/styles.css, /assets/...) da bi radile na domen-u.
- Ako vidite staru verziju: Cloudflare Dashboard → Caching → Purge Everything (ili samo URL).

Lokalno (Live Server):
----------------------
1. Otvorite folder repoa time-caffe (koren – gde su index.html, wrangler.toml).
2. Desni klik na index.html → Open with Live Server.
3. Adresa npr. http://127.0.0.1:5500/ – meni: /meni.html.

Stari problem "Cannot GET /time-caffe/frontend/meni.html":
-----------------------------------------------------------
- Pojavljivao se kada je Live Server bio na pogrešnom root-u. Sada je sajt u korenu repoa,
  bez podfoldera frontend.

Backend (meni iz baze):
-----------------------
- U folderu backend: npm install, pa npm run dev.
- Baza: kreirati time_caffe, pokrenuti database\schema.sql.
- Kada je backend uključen, "Naš meni" i stranica "Meni" učitavaju
  stavke iz baze; inače se prikazuje ugrađeni spisak.
